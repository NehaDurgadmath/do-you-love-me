## ✨ What is this?

A playful, romantic, share-worthy mini web game where the page asks:

> **"Do you love me?"**

There are two buttons — **Yes 💕** and **No 🙈**

But every time you click **No**, something adorable happens... 😏

<br/>

## 🎮 Game Logic

| Click | What Happens |
|-------|-------------|
| **Yes** 💕 | Instant love celebration — hearts, sparkles, dancing characters! |
| **No #1** | *"Wrong answer!"* 😤 |
| **No #2** | *"Excuse me… what are you doing?"* 😒 |
| **No #3** | *"Babe, don't make me cry…"* 😭 |
| **No #4** | *"You're breaking my heart…"* 💔 |
| **No #5** | The **No** button disappears forever 😡 |
| **Only Yes left** | You have no choice now, babe 💕 |

<br/>

## 💫 Features

- 🐰 **Cute anime-style characters** — boy & girl react emotionally to every click
- 📈 **Yes button grows** bigger after every No
- 📉 **No button shrinks** smaller after every No
- 🎵 **Sound effects** — built-in AudioContext sounds (no external files!)
- 💖 **Heart explosion** on the final love screen
- ✨ **Floating sparkles** and animated background hearts
- 🌸 **Smooth animations** for every character emotion
- 📱 **Fully responsive** — works on mobile, tablet & desktop
- 🎨 **Pastel glassmorphism** aesthetic — Pinterest-worthy design
